A retry loop hands in its resignation: after 47 retries it finally gets a 200 and realises nobody was waiting for the answer anymore.

## Run it

```sh
node main.ts
```

The program writes the one line to the directory named by `MAKEFUN_OUTPUT_DIR` (default `/output`) as `entry.txt`.
